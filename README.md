Two lines to my past self: a warning about one specific moment, and one sentence on why it mattered. Line one warns not to send an angry text to Maya on a Friday night; line two says that one unsent message kept the friendship alive, and taught me never to argue after midnight. The program writes the two lines to `entry.txt` (UTF-8, 184 characters, no trailing newline).

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/past-self-out python3 main.py
```
